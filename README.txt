KLS SameDay Office v19 — Route Planner

INSTALL
1. Run KLS_SameDay_v19_Route_Planner.sql in Supabase SQL Editor once.
2. Replace app.js, styles.css, index.html, manifest.json, sw.js, build.js and package.json in GitHub.
3. Keep your existing config.js.
4. Commit: Upgrade to v19 Route Planner
5. Wait for Vercel Ready, then hard refresh.

WHAT IS INCLUDED
- New Route Planner page
- Planning by collection date
- Unassigned job lane
- Driver route lanes
- Drag jobs onto a driver route
- Saved route assignment and stop order
- Driver assignment updates on the original job
- Planned job, mileage and revenue totals
- Responsive mobile layout

IMPORTANT
This version uses the mileage already saved against each job. It does not connect to a paid postcode, traffic or route-optimisation API. The route order is the order in which jobs are added to a driver's lane.
