KLS SameDay Office v20 — Online Quotes & Booking Requests

INSTALL
1. Run KLS_SameDay_v20_Online_Quotes.sql in Supabase SQL Editor once.
2. Replace app.js, styles.css, index.html, manifest.json, sw.js, build.js and package.json in GitHub.
3. Keep your existing config.js.
4. Commit: Upgrade to v20 Online Quotes
5. Wait for Vercel Ready, then hard refresh.

WHAT IS INCLUDED
- Secure public quotation links
- Customer accepts or declines online
- Customer name, message and response time saved
- Public website quote request form
- Online Requests dashboard with pending badge
- Convert a public request into the existing quote builder
- Copy-link buttons for email, WhatsApp or your website

IMPORTANT
- This version does not automatically send email or take card payments.
- Public quote links expire after 30 days by default.
- Run select public.claim_public_quote_requests(); once after the first public request arrives so existing unclaimed requests attach to your office account.
