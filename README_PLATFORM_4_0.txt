KLS SameDay Platform 4.0 — Live Dispatch Board

New in this version:
- Five-column live dispatch board
- Drag and drop job status updates
- Job/customer/postcode/driver search
- Driver filter
- Live Supabase updates for jobs, drivers and Driver Exchange
- Collection alert KPI
- Live GPS summary and fleet map
- Mobile-responsive control board

Deployment:
1. Keep your existing config.js / Vercel Supabase environment variables.
2. Upload all files in this folder to the existing GitHub repository.
3. Commit and wait for Vercel to deploy.
4. Hard refresh and open Dispatch Centre.

No new SQL migration is required for this upgrade if Platform 3.1 is already working.
