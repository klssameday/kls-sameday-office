KLS SameDay Platform 5.0 - Customer Portal

WHAT IS NEW
- Expanded customer booking form
- Required delivery date and time
- Weight, dimensions and contact details
- Customer saved address book
- Faster repeat bookings
- Existing live tracking, POD links, invoices and rebooking retained

INSTALLATION
1. Run KLS_Platform_5_0_Customer_Portal.sql in Supabase SQL Editor.
2. Keep your existing working config.js.
3. Upload the remaining files to GitHub, replacing the previous platform files.
4. Allow Vercel to redeploy.

TEST
- Sign in with a linked customer account.
- Save an address.
- Submit a booking request with delivery requirements.
- Confirm the request appears in the Office Customer Portal screen.
