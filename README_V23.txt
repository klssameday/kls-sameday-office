KLS SameDay Office v23 — Mobile Driver Mode

INSTALL ORDER
1. In Supabase, open SQL Editor > New query.
2. Run KLS_SameDay_v23_Driver_Mode_Migration.sql once.
3. Upload these files/folders to the root of your GitHub repository:
   index.html
   app.js
   styles.css
   offline.html
   manifest.json
   sw.js
   build.js
   package.json
   icons/
4. DO NOT replace your existing config.js.
5. Do not upload config.example.js as config.js.
6. Commit summary: Release v23 - Mobile Driver Mode
7. Wait for Vercel to show Ready.
8. Close and reopen the installed Mac/iPhone apps. If needed, hard refresh Safari.

V23 FEATURES
- Mobile Driver App page
- Active, Today and All job filters
- Start Job one-tap action
- Navigate to collection or delivery
- Call customer
- Share job details
- Job progress indicator
- One-tap status updates
- Automatic started_at and collected_at timestamps
- Live GPS tracking while Driver App remains open
- Customer tracking link sharing
- POD photo capture
- Recipient signature
- Recipient name and delivery notes
- Save POD and mark delivered

IMPORTANT
Live browser/PWA tracking works while the Driver App remains open and location permission is allowed. iPhone background tracking while the phone is locked requires a native app.
